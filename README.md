# Harf & Nuqta — Official Digital Bookstore
**Domain:** [https://harfnuqta.store](https://harfnuqta.store)

Premier digital PDF bookstore for verified eBooks on politics, history, and constitutional thought. Featuring *Iqtidaar Ke Paar* (اقتدار کے پار) & *Beyond Power* by Rashid Yousafzai & Muhammad Amin Asad.

## Features
- **Modern Responsive Design:** Tailored for mobile, tablet, and desktop readers.
- **Multilingual Support:** English and Urdu switchable interface.
- **Instant Digital Delivery:** WhatsApp & Email checkout integration.
- **SEO Optimized:** Full Open Graph, Twitter Cards, Sitemap, and Schema.org Rich Snippets (BookStore, Book, FAQPage).
- **Fast Production Ready:** Optimized for LiteSpeed / Apache hosting on Hostinger.

## Deployment
This repository is configured for automated deployment to Hostinger `public_html`.
Whenever changes are pushed to the `main` branch, Hostinger pulls the latest update via Git Webhook.
